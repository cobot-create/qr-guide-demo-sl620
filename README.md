# QR案内ページ - サンプルデモ

これは「QRで見せる、自分でいつでも直せる案内ページ」というサービスの**サンプルデモ**です。
**実在の店舗ではありません。** 店名・メニュー・価格はすべて架空のものです。

## これは何か

- QRコードを読み取ると開く、スマートフォン向けの案内ページ（飲食店メニューを想定）
- 中身は外部の表（実運用では Google スプレッドシート）から読み込まれる
- 店主が表の1セルを書き換えると、ページの再読み込みで内容が反映される
- 日本語 / English の表示切替つき

## このデモでの実装メモ

- 本番運用では `app.js` の `DATA_URL` に、Googleスプレッドシートの「ファイル > 共有 > ウェブに公開 > CSV」で発行されるURLを設定する。
- このデモ環境自体は、実行環境からブラウザ操作でGoogleアカウントを新規操作できないため、同一リポジトリ内の `data.csv` を「同等の外部シート」として使用している（パーサーはGoogleスプレッドシートのCSV出力にもそのまま対応）。
- ビルド不要（静的HTML+CSS+JSのみ）。GitHub Pagesでホスティング。
